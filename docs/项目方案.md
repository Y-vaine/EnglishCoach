# 个人英语教练：Codex + Obsidian 统一方案 v2.0

日期：2026-10-04。状态：首版已实现本地工具和 Obsidian 学习空间，手机真实语音验收及 Figma 设计稿待完成。本文件完整替代历史方案，是当前唯一有效需求。旧版本仅在 Git 历史中保留。

## 1. 产品定位

Codex 是个人英语教练与实际对话入口；Obsidian 是漂亮、温暖、有宠物陪伴的学习空间，也是唯一长期知识库；Figma 用于视觉设计。GitHub 保存开发与设计的版本历史。

服务中国职场新人，职业领域为采购数字化、AI Agent 和项目管理。目标包括职场沟通、雅思口语和英语心情日记，默认每天 15 分钟，支持 3–5 分钟低精力练习。

主流程：打开 Codex → 说“开始今天的练习”或“今天想聊日记” → 文字/可用语音回答 → 反馈与追问 → 再次表达 → 结束总结并自动写入 Obsidian → 回顾与复习。

不开发微信小程序、独立 Web 应用、独立录音界面或云端学习数据库。无需 React、FastAPI、公网服务器或单独的 AI API 作为首版前提。专用发音评估只作为条件满足后的可选增强。

## 2. 各工具的职责与展示位置

| 工具 | 职责 | 用户在哪里看到 |
|---|---|---|
| Codex | 场景、对话、纠错、追问、总结、调用归档工具 | Codex 聊天区或可用的手机 Remote 会话 |
| Obsidian | 今日书桌、宠物插画、日记、练习记录、表达与成长回顾 | Obsidian 桌面或移动 App |
| Figma | 学习空间版式、配色、封面、宠物状态素材 | 设计文件，导出后用于 Obsidian |
| 本地文件工具 | 写入校验、恢复、复习日期、索引生成 | 幕后运行，状态由教练反馈 |
| GitHub | 代码、设计素材、模板与方案历史 | EnglishCoach 仓库 |

漂亮界面位于 Obsidian，而不是替换 Codex 的聊天皮肤。电脑上可以并排打开 Codex 和 Obsidian；手机上在聊天与 Obsidian 之间切换，不承诺两个 App 同屏显示宠物。首页的“开始练习”提供可复制口令，默认不会自动向 Codex 发消息。

## 3. 手机优先的使用路线

用户主要使用手机，希望用 ChatGPT 手机 App 语音。优先验证通过 Remote 连接电脑上的 EnglishCoach 项目，以相同教练规则、学习记录和本地工具练习。宿主语音能力由账号、系统、版本与可用入口决定。

手机验收链路：打开项目 → 读取档案 → 三轮语音 → 修正一次转写 → 说“结束练习” → 核对 Vault 中记录与完整度。先做这项最小验证，再扩大视觉和内容制作。

使用本机 Vault 时，负责文件写入的电脑须在线且宿主能调用工具。普通 ChatGPT 语音聊天不能默认读写电脑 D 盘。手机端无连接时的练习不宣称自动归档成功；用户可提供可访问记录辅助导入，但此路线标记为辅助模式。

Obsidian 移动端访问同一 Vault 需要独立可用的同步方案。当前电脑的 OneDrive 文件夹不代表手机 Obsidian 已能打开同一 Vault；开发前按手机系统验证文件访问和同步，必要时评估同步服务的费用。不修改用户现有同步配置，也不保证 OneDrive 在所有手机系统上可直接作为 Vault。

## 4. 教练的三个模块

### 职场英语

覆盖项目汇报、AI 项目介绍、领导沟通、会议讨论、供应商沟通、工作总结。首批从 6 张核心场景卡做起，验证质量后扩充到 30 张。

场景包含角色、稳定事实、沟通目标、追问方向、难度、目标表达和完成标准。支持两周连续剧情，例如供应商资料审核 Agent 的需求、立项、接口对接、进度和试点总结；允许随时选择独立场景。

完成标准是解释清楚、能回应追问、提出明确行动，不要求背诵固定答案。业务建议与英语错误分开反馈。

### 雅思口语

覆盖 Part 1/2/3 专项，后续完整模考。训练与模考分离：训练可提示与纠错，模考结束后反馈。共享理由、举例、比较和叙事等能力标签，但保持职场与考试语域差异。

按官方口语四维组织证据反馈。文字与仅转写不能评估真实发音、语速和停顿，不输出虚构总分。雅思听力、阅读与写作专项不属于当前交付。

### 心情日记

默认温暖朋友语气，可选反思导师、英语教练。允许“只听我说”“不要建议”“最后纠错”“用中文解释”。角色是 AI 沟通风格，不是人类身份或专业心理资质。

先回应内容，再帮助表达。默认聊两三个回合后整理 1–2 项语言改进；允许中英文混合，不强迫积极结尾，不因用户自述敏感建立诊断或人格标签。

结束保存用户原文、可访问对话、保持本人感受的英文成稿、纠错与可选反思。改写不替换原文，不加入不存在的事实或励志结论。日记不默认进入职场场景检索；提炼语言卡时去除私人背景。

用户可选择只保存成稿，或说“这一段不要记”。不记录段落也不生成衍生学习卡，不承诺清除无法控制的宿主服务记录。

## 5. 每次练习的教学闭环

1. 读取学习档案、少量到期复习、近期场景与未完成练习。
2. 一句话说明任务，默认不提前给完整示范答案。
3. 每次只问一个问题，让用户充分表达。
4. 先回应内容，再纠正 1–2 个重点，附简短中文解释。
5. 给可复述自然版，可选进阶版；不把正确表达误报为错误。
6. 关键轮次请用户先不看示范再说一次；记录提示程度。
7. 依据回答继续追问，默认 4–6 个对话轮次，可随时结束。
8. 生成总结、最多三项学习资产与下次目标，保存后读回确认。

提示按关键词 → 结构 → 开头 → 示范逐步增加，随学习进展减少。朋友模式可先连续聊天，教练模式更集中纠错。语音反馈短而自然，详细解释写入笔记。

## 6. Obsidian 视觉与宠物

风格默认奶油白、鼠尾草绿与杏色点缀，温暖安静的书桌。文字清楚、对比足够、手机布局简洁，避免整页红色错误和密集评分。

采用专用笔记 cssclasses、局部 CSS 片段、Markdown 模板与 SVG/PNG 素材。不整体更换 Vault 主题，不影响其他工作笔记。实现时允许在 .obsidian/snippets 中新增一个有明确命名的样式文件；不直接改动现有主题或插件设置。样式启用方式实测，不假设复制 CSS 就自动生效。

Figma 交付：电脑/手机的首页、会话总结、日记与成长回顾设计，色彩和排版规范，宠物素材状态板。导出素材并转化为 CSS/Markdown 才能在 Obsidian 显示。原型不视为已实现界面。

### 学习空间

- Home.md：宠物、温柔问候、今日推荐、继续练习口令、三个模块、少量待复习内容。
- 会话笔记：原回答、纠错、自然表达、再次表达与总结，结构清晰。
- 日记：安静布局，原文与成稿分开，不强制评分。
- 表达收藏：按汇报、澄清、不同意见、情绪表达等用途组织。
- 成长回顾：用“以前怎么说 / 现在怎么说”与提示减少展示进步。

### 宠物实现

暂定原创圆润小猫，可改名。它属于 Obsidian 学习空间，不默认采用 ChatGPT Work Pets。

首版采用待机、欢迎、鼓励和完成后的静态状态素材；可选轻量循环动画，但是否在桌面/手机正常显示需要验证。Codex 保存笔记时更新宠物状态，Obsidian 刷新后展示。它不会实时监听 Codex 麦克风、追踪情绪或自动同步每个对话动作。

可通过完成练习解锁纪念贴纸与书桌装饰。没有断签惩罚、饥饿或生病，无排他性情感表达。宠物和装饰可关闭，不阻碍学习。真正桌宠或交互式宠物需要插件，当前不作为首版前提。

学习内容、复习状态与宠物成长状态都保存在 Markdown/YAML。录音与图片是附件，不能声称二进制文件是 Markdown。缓存可删除并从 Vault 重建，不另建云端知识库。

元数据保存 session_id、日期、模块、角色、输入方式、提示水平、来源和完整度。按 Asia/Shanghai 处理日期。会话 in_progress、summary_pending、completed 与完整度 complete/partial 分开。

文字练习逐轮保存；语音只在实际可取得内容与工具调用的边界保存检查点，不保证完整逐字稿或原始音频。缺失内容明确标记，不编造原回答。结束口令触发总结；只关闭界面不等于完成归档。

工具校验路径、固定 ID、重复轮次、并发与人工编辑，使用临时文件替换并写后读回。中断能恢复已保存检查点；不可写时保留待归档 Markdown 并明确提示未归档，不虚报成功。

默认只读写 EnglishCoach 与新增的专用 CSS 文件；不读取整个 Vault。人工备注不被覆盖，不安装不必要的社区插件。

## 8. 复习与成长

每天最多新增三项：错误模式、表达卡、任务模板。每日复习最多三项或三分钟，暂按 1/3/7/14 天透明规则，根据表现调整；py-fsrs 作为后续候选。

分别记录记忆结果和独立表达质量。看答案复述不算掌握，跨场景独立使用才记为迁移证据。不把宠物解锁当作英语水平证明。

首次用工作介绍、进度汇报和经历题做基线。每四周重做同类任务，区分原题熟悉与新题迁移。周报引用实际回答，缺少语音数据时不推算发音或流利度。

## 9. 语音、发音与费用

复用宿主提供的语音聊天/听写，不自建 ASR/TTS，不额外购买语音资源包作为首版条件。用户可纠正识别错误，保存修订与来源。

只有文字或转写：提供读法、重音与造句建议，实际发音标为未评估。实际音频可访问且评估能力有效时：指出具体问题并让用户重读。专业音素和节奏反馈作为可选增强，需先验证音频访问、准确性和额外成本，不能用转写成功代替发音正确。

费用目标：已有 Codex 订阅额度足够时尽量不新增 AI/API、服务器与小程序费用；不承诺无限或免费。Figma 使用用户现有会员，不默认购买额外插件。手机 Vault 同步可能产生独立费用，需要选型后确认。电脑在线运行也属于使用成本。

不为节省成本承诺宿主无法实现的自动归档或专业发音评分。手机路线未验证通过时明确报告，而不是用手动导入冒充全自动。

## 10. 技术实现与 Git

项目包含项目级 AGENTS.md、可复用教练 Skill、场景卡、Markdown 模板、本地 Python 文件工具、CSS 和视觉素材。Skill 在实现阶段按 skill-creator 工作流制作。依赖尽量少，无独立前端服务器。

本地工具职责：加载学习上下文、创建/追加/结束会话、记录复习、生成首页与回顾、更新宠物状态、重建索引。工具不调用额外大模型，语言反馈由 Codex 完成。

GitHub：https://github.com/Y-vaine/EnglishCoach ，已连接公开仓库。main 已有推送记录；每次完成变更做适当检查、提交、推送、核对本地与远程 HEAD。提交邮箱沿用用户已提供的配置，不在文档重复个人联系方式。

仓库只保存方案、规则、工具、模板、视觉资源和虚构测试样例。真实日记、录音、学习档案、密钥和用户机器配置不提交。Figma 链接及设计导出纳入版本管理，设计文件自身历史与 Git 历史分别管理。

## 11. 交付顺序与验收

| 阶段 | 交付 | 通过标准 |
|---|---|---|
| A：手机与归档验证 | 最小教练规则、文字样例、Remote 语音实测 | 回答来源明确，记录确实进入 Vault；手机查看同步另行验证 |
| B：可用教练 | 三个模块、重点纠错、复述、总结、恢复、基础复习 | 一句话启动，结束无需手动导出，新会话能恢复背景 |
| C：漂亮学习空间 | Figma 设计、局部 CSS、模板、原创宠物素材 | 桌面/手机可读，其他笔记不受影响，局部样式可关闭 |
| D：长期优化 | 场景扩充、周报、迁移检查、宠物装饰 | 内容来自真实记录，负担可控，没有惩罚性设计 |

发音专项独立于上述交付，只有音频与能力验证成功才加入。每次交付说明完成内容、验证、局限、Git 提交与同步状态。

当前方案不创建 Figma 文件、不更改 Vault 配置、不安装 Skill；这些在实施阶段执行。Git 已可用，不代表手机归档、同步和视觉已经完成。
