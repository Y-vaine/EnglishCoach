# EnglishCoach 首版使用指南

## 使用

在本项目 Codex 中说：`开始今天的练习`、`今天想聊日记`、`练雅思口语`、`继续上次练习`。结束时说 `结束练习`。可以用手机 Remote 的可用文字/语音入口；电脑须在线。真实语音链路仍需一次实际练习验收。

Obsidian 打开 `EnglishCoach/Home.md`，使用阅读视图。设置 → 外观 → CSS 代码片段 → 启用 `englishcoach`。首页口令用于复制到 Codex，不是可点击的聊天启动按钮。小猫为静态状态插画，保存时更新。手机 Vault 同步仍由你现有 Obsidian 同步方式负责。

“不要记这段”会要求教练排除该段和衍生成果。当前轮尚未保存时直接排除；已保存时需针对记录及衍生卡片清理。仅有转写时可以纠正语法/造句、给发音示例，不能评价实际发音。

## 本地工具

Python 3.10+，只用标准库，无数据库、服务器或付费 API。复制 `local.settings.example.json` 为 `local.settings.json`，填本地 Vault。执行 `python coach.py init` 初始化，已有笔记不覆盖。同名 CSS 不一致时停止。配置文件与 `runtime/` 被 Git 忽略。

通用：`python coach.py <command> --input runtime/payload.json`；读取不需要输入文件。所有输入 UTF-8 JSON。真实内容不得作为命令行参数或提交到 Git。

| command | 输入/结果 |
|---|---|
| init | 建目录、模板、6 个场景、小猫素材及局部 CSS |
| context | 档案、最近 3 次、未结束练习、最多 3 张到期卡片、今日场景 |
| start | `{"module":"work","title":"项目汇报","prompt":"Give a short update.","source":"codex-text","completeness":"complete"}` → ID/版本 |
| read | `--id s-...` → 完整状态 |
| append | `{"id":"s-...","version":1,"turn":{"id":1,"user":"...","coach":"...","hints":false}}` |
| finish | `{"id":"s-...","version":2,"summary":"...","completeness":"partial"}` |
| card | `{"session_id":"s-...","title":"礼貌询问","content":"Could you give me an update?","category":"expression"}` |
| review | `{"id":"c-...","version":1,"event_id":"unique-id","result":"good"}`；again/hard/good/easy |
| redact | `{"id":"s-...","version":3,"turn_ids":[1]}`；清除指定轮及本次全部衍生卡/总结，重建回顾 |
| home | 重建首页索引，保留私人便签 |
| weekly | 近 7 日实际总结，保留个人感想，不捏造提升分数 |

模块：work / ielts / journal。persona：friend / mentor / coach。记录保存在 Sessions 或 Journal 的年月目录。每次最多 3 张卡；初次次日复习，成功后 3/7/14/30 天，again/hard 次日再练。复习结果由实际回忆表现确定，不由练习次数推断。

记录采用 Markdown/YAML，加可折叠 JSON 工具状态；不是另外一套知识库。修改请写在“我的补充”下。管理区改动会触发保护。原子写入、读回校验、操作锁、版本检查和 ID 去重减少重复/覆盖风险；OneDrive 冲突副本仍需要人工处理。工具报错后先 read，不能把整体报错等同于从未保存。

## 验证

`python -m unittest discover -s tests -v` 使用临时 Vault 和模拟文本，不接触私人数据。验收手机：开始 → 3 轮真实回复 → 修正一次转写 → 结束 → 核对 Vault 原文、总结及完整度。首版不包含精确发音评估、手机同步服务或实时宠物动画。
