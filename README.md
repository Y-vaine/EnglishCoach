# EnglishCoach

Codex 个人英语教练 + 漂亮的 Obsidian 学习空间：职场英语、雅思口语与心情日记，搭配宠物素材、局部样式和 Markdown 自动归档。

首版已实现本地 Markdown 归档工具、三个模块的教练 Skill、复习卡片、成长回顾，以及带原创小猫的 Obsidian 首页和局部 CSS。不开发独立应用或微信小程序。AI 对话由 Codex 执行。

在本项目说“开始今天的练习”或“今天想聊日记”。部署、工具用法及限制见 [使用指南](docs/使用指南.md)。手机 Remote 的真实语音归档仍需用户实际练习验收；Figma 连接未登录，尚未创建设计稿。

开发验证：Python 3.10+，`python -m unittest discover -s tests -v`。无额外 Python 依赖。

完整需求见 [项目方案](docs/项目方案.md)。私人学习内容保留在用户 Obsidian Vault，不进入本仓库。
